🎨 plot-ts 动画图表库

基于 ECharts 封装的 Matplotlib 风格 API - 流畅动画 · 响应式布局 · 交互友好

📈 折线图 - 多系列动画

fig.plot(x, y, { smooth: true, name: '数据' })

⚬ 散点图 - 弹性动画效果

fig.scatter(x, y, { size: 8, opacity: 0.7 })

📊 柱状图 - 渐进式动画

fig.bar(categories, values, { stack: false })

📈 面积图 - 层叠效果

fig.area(x, y, { stack: true, opacity: 0.3 })

🔥 热力图 - 数据可视化

fig.heatmap(matrix, xLabels, yLabels)

🦋 洛伦兹吸引子 - 混沌系统

fig.scatter(x, y, { size: 3, color: '#667eea' })

🎻 小提琴图 - 分布可视化

fig.violin(groups, distributions)

📡 实时数据流 - LIVE

fig.stream(generator, 500, 50) // 500ms间隔, 保留50点
